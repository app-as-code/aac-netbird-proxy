# Icon source

The icons are downloaded from the icon collections of the self-hosted community:

- `icon.svg` (default, colored logo) comes from `homarr-labs/dashboard-icons`
  (`svg/netbird.svg`, served via jsdelivr).
- `icon-dark.svg` (white logo, used in dark mode) and `icon-light.svg` (black logo, used
  in light mode) come from `selfhst/icons` (`svg/netbird-light.svg` and
  `svg/netbird-dark.svg`).

No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `homarr-labs/dashboard-icons` `svg/netbird.svg` | Default |
| `icon-dark.svg` | `selfhst/icons` `svg/netbird-light.svg` | Dark color scheme |
| `icon-light.svg` | `selfhst/icons` `svg/netbird-dark.svg` | Light color scheme |

Download URLs:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/netbird.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/netbird-light.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/netbird-dark.svg
